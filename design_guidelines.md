# Design Guidelines: AI-Powered Career Guidance Platform

## Design Approach

**Selected Framework**: Modern SaaS Platform with Light Theme  
**Primary References**: Linear (clean typography), Stripe (clarity and trust), Notion (light, airy design)  
**Justification**: Light, professional design with blue-purple gradients creates a trustworthy, accessible platform for career development.

## Visual Theme

**Color Strategy**: Light theme with blue-purple gradient accents
- Blue-purple gradient: Professional, creative, innovation-focused
- Light backgrounds with subtle contrasts
- Maintain high contrast ratios for accessibility

## Typography Hierarchy

**Font Selection**: Inter
- **Primary Font**: Inter (all text) - weights: 400, 600, 700

**Typography Scale**:
- Hero Headline: text-5xl md:text-6xl lg:text-7xl, font-bold
- Section Headlines: text-3xl md:text-4xl, font-bold
- Card Titles: text-xl md:text-2xl, font-semibold
- Body Text: text-base md:text-lg, font-normal

## Layout System

**Spacing Primitives**: Consistent spacing with py-16 md:py-20 sections
- Scrolling vertical layout for all sections
- Full-width sections with centered content

## Navigation

**Header**: Fixed navigation bar with logo and menu items
- Logo on left
- Navigation items: Career, Courses, Assessment, Profile/Login
- Clean, minimal design

## Page Structure

### Hero Section
- Gradient headline with blue-purple theme
- Subheading and CTA
- Hero image with gradient overlay

### Resume Upload Section
- File upload input (PDF, DOCX)
- Text input alternative
- Prominent placement after hero

### Features Section
- Vertical scrolling cards
- Each feature displayed prominently
- Icons with blue-purple accent colors

## Component Library

### Buttons
- Primary CTA with blue-purple gradient or solid primary color
- Smooth hover effects
- Size variants for different contexts

### File Upload
- Drag-and-drop area
- File type indicators
- Text input alternative

## Responsive Behavior

- Mobile-first approach
- Stacked layouts on mobile
- Navigation menu collapses on mobile

## Colors

- Light background (white/off-white)
- Blue-purple gradient accents
- Subtle borders and shadows
- High contrast text for readability
