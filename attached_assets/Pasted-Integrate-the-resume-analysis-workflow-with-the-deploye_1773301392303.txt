Integrate the resume analysis workflow with the deployed n8n webhook and implement the results UI.

The system must allow a user to upload a resume (PDF or TXT), send it to the webhook, process the response, and display job matches in a modal popup with cards.

Do not change the current project architecture. Only add the integration and UI.

------------------------------------------------

WEBHOOK DETAILS

Webhook URL:

https://n8n-workflow-i5z9.onrender.com/webhook/resume-upload

Request Method:

POST

Content-Type:

application/json

------------------------------------------------

REQUEST BODY FORMAT

The webhook expects this exact JSON structure:

{
  "fileName": "resume.pdf",
  "fileBase64": "BASE64_STRING"
}

fileName must be the uploaded file name.

fileBase64 must be the Base64 content of the file without the data prefix.

Example conversion:

reader.result.split(",")[1]

------------------------------------------------

IMPLEMENT FILE BASE64 CONVERSION

Create this helper function:

function convertToBase64(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();

    reader.onload = () => {
      const base64 = reader.result.split(",")[1];
      resolve(base64);
    };

    reader.onerror = reject;

    reader.readAsDataURL(file);
  });
}

------------------------------------------------

WEBHOOK REQUEST FUNCTION

Create the function:

async function sendResumeToWorkflow(file) {

  const base64 = await convertToBase64(file);

  const response = await fetch(
    "https://n8n-workflow-i5z9.onrender.com/webhook/resume-upload",
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        fileName: file.name,
        fileBase64: base64
      })
    }
  );

  const result = await response.json();

  return result;
}
